## Content ID caveat

- **Kevin MacLeod / incompetech:** his catalogue is *pre-registered* in Content ID by the licensor (Frequency / Kelvin Ruijters). A claim is expected if the description credit is missing; adding the credit then disputing releases it, normally within 72 h (https://incompetech.com/music/royalty-free/youtube-contentid.html). Third parties also file false claims on his music. So: always put the credit in the description BEFORE upload; expect a possible temporary claim on first upload; keep this file as proof. Revenue can be redirected while a claim is open.
- **Mixkit SFX:** the Free License allows commercial/YouTube use without attribution. Mixkit does not address Content ID; a third-party claim is possible but not expected for short effects. Keep the download record (this file).
- Mixkit files are the site's `-preview.mp3` (the public, no-login download; ~128 kbps), not lossless WAV.
